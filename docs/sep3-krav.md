# SEP3 Project Requirements, krav for krav

Kilde: `SEP3 Requirements.pdf` (én side), læst 2026-09-23. Kopi ligger i denne mappe.
Excel- og Word-udgave: `~/Downloads/SEP3 Requirements.xlsx` og `.docx`.

| # | Kategori | Krav | Detaljer |
|---|----------|------|----------|
| 1 | Proces | Vælg og anvend en softwareudviklingsmetode | Fx Scrum eller AUP, skal bruges gennem hele udviklingsprocessen |
| 2 | Proces | Frit valg af domæne | Forslaget skal godkendes af vejlederne |
| 3 | Proces | Projektet skal være under versionskontrol (Git) | Gælder hele udviklingsprocessen |
| 4 | System | Distribueret system | Fra SEP3 kursusbeskrivelsen |
| 5 | System | Heterogent system | Både Java og C# skal bruges |
| 6 | System | Server-til-server-kommunikation | Et rent klient-server-system er ikke nok |
| 7 | System | Mindst to forskellige netværksteknologier | Fx REST, gRPC, RabbitMQ, sockets, GraphQL |
| 8 | System | GUI til klienten/klienterne | |
| 9 | System | En eller flere databaser | |
| 10 | Rapport | Afsnit om valg af teknologi og arkitektur | Skal sammenlignes med alternative tilgange |
| 11 | Leverance | Formelle upload-kriterier for SEP skal overholdes | Link i PDF: "Formalities Criteria For Upload Of SEP" på my.via.dk |
| 12 | Leverance: Rapport | 8 til 12 sider | 1 side = 2400 tegn inkl. mellemrum, bilag tæller ikke med |
| 13 | Leverance: Kildekode | Hele projektets kildekode som .zip | |
| 14 | Leverance: GitHub | Link til kildekoden på GitHub | Skal ligge i filen `github.txt` |
| 15 | Leverance: Video | Link til videodemonstration af det komplette system | Skal ligge i filen `demo.txt`, max 3 minutter |
